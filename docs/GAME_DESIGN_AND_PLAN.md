# 《幽林余烬 · Blackwood Ember》游戏设计与分阶段开发计划

> 定位：**点开即玩的《阴暗森林 Darkwood》风格俯视角心理恐怖生存 Web 游戏**。
> 协作分工：主策划 / 主美 / 验收官负责标准、接口契约与每阶段门禁审查；开发子 Agent 按独立任务包（Task Packet）执行落地与自测。

---

## 一、核心体验支柱（Design Pillars）

1. **点开即玩，30 秒入戏（Zero-Friction Dread）**
   - 标题页即是实时雨夜庇护所，点击「开始求生」无黑屏跳转，镜头直接推入庇护所内。
   - **第 1 天前 30 秒必有强引导事件**：庇护所外短促的敲门/挠门声（附声波涟漪）→ 一盏摇曳的发电机灯泡 → 门口一具留有字条与基础物资的遇难者背包，无需弹大段新手教程即可让玩家自然学会：瞄准照亮 → 搜刮 → 修门/拖家具 → 探索。
2. **光影即恐惧（Vision-Cone Paranoia）**
   - 玩家手电锥光之外只保留低饱和、模糊的“环境记忆轮廓”，**看不见视野外的潜行怪物**。
   - 黑暗中的威胁主要通过**立体声方位音频（脚步、刮木、低吼）+ 微弱声波涟漪 + 闪电瞬间暴露剪影**来制造心理恐怖，杜绝廉价跳脸（Jump Scare）。
3. **白昼贪婪搜刮 × 黑夜防线博弈（Day Greed vs. Night Siege）**
   - **白昼（85s）**：深入 4 大风格地标（坠毁货车、废弃锯木厂、猎人营地、枯林祭坛）搜刮燃油、木板、废铁与关键逃生部件；探索越深收益越高，但距离庇护所越远、返程风险越大。
   - **黄昏（20s）**：雾气骤浓、远处低沉号角与林间鸦鸣催促回巢；回屋加燃油、钉木板、**拖拽屋内家具（木桌/沙发/柜子）抵住薄弱门窗**、布设捕兽夹。
   - **黑夜（70s）**：发电机维持室内暖光（熄火则陷入致命黑暗）；怪物先在屋外徘徊试探（挠门、绕窗偷窥），再集中破门；玩家需在修防线、扔照明弹、蓄力近战与闪避周旋间做资源抉择。
4. **明确可通关的 10–15 分钟完整弧光（Win Condition）**
   - 避免“无尽刷怪直到死”的疲劳感，建立**可通关的「余烬逃生」目标**：
     - 在林区 3 处关键地标找齐 **3 个「信号中继零件（Relay Parts）」**（分别位于坠毁货车、废弃锯木厂、枯林祭坛，日志草图上标注大致方位而非精确 GPS）；
     - 将零件装入庇护所发电机/电台，并在**最终之夜（或凑齐后触发的撤离夜）**坚守至黎明破晓，触发**「破雾撤离」通关结局画面**（同时保留「继续无尽求生」入口）。

## 二、现状深度诊断（基于 `baseline_v0` 实测）

| 维度 | 当前现状 | 与目标体验的差距 | 改造方向 |
|---|---|---|---|
| **主美与色彩** | 白天 `L=34.1`, `colorful=26.1`, `greenDom=0.40` | 草地过绿过亮、建筑纹理偏规整塑料感、缺少 Darkwood 的冷灰腐朽压迫感 | 重构调色板与 WebGL2 后期，加入枯枝根须、黑边截断墙顶、门窗缝隙光束 |
| **视野与恐怖感** | 视野锥外依然清晰可见实体与背景 | 缺少“背后看不见东西、只能听声辨位”的核心恐惧 | 实现视野锥外灰度压暗 + 怪物视野剔除（闪电/近身/声波短暂暴露） |
| **防线与战斗** | 只有按 E 修木板 + 无脑左键平砍 | 缺乏策略纵深与近战博弈，夜战容易站桩换血或瞬间暴毙 | 增加**可拖拽家具堵门**、**蓄力重击 + Space 闪避**、重调夜袭节奏（窥伺→破门→突袭） |
| **局内目标** | 无通关结局，只有无尽天数 | 点开即玩缺乏终极正反馈与高潮收尾 | 增加 **3 件中继零件收集 + 终夜坚守逃生结局** + 顶部极简目标提示 |
| **工程与门禁** | 仅有纯 Node `sim-check.ts`，页面含 2 个 404 及 Google Fonts 外链 | 缺少无头浏览器 UI/布局/弹层/性能/主美色彩门禁，离线不纯净 | 移除外链与 404；补全 Tier 1 + Tier 2 全套自动化无头门禁 |

## 三、分阶段里程碑与任务拆分（面向子 Agent 执行）

每个阶段均遵循：**子 Agent 开发 → 跑通本阶段必过门禁 → 主美/验收官审查截图与指标 → 放行下一阶段**。

### Phase M0：工程清理与全套自动化门禁基建（Testability-First）
> 目标：先造“眼和手”，消除所有 404 与外链，建立不可绕过的自动化验收防线。
- **T0.1（工程纯净与离线化）**：
  - 移除 `index.html` 的 Google Fonts 外链，改用纯系统优雅衬线/无衬线字体栈；修复 `index.html` 中文编码问题（防止乱码）与 `favicon` 404；排查并清零 `baseline_v0` 中出现的 2 个 404 请求；将参考视频 `public/assets/aistudio/*.webm` 移至 `docs/art/ref_videos/`，避免被打包进游戏发布产物。
- **T0.2（补齐 `window.__game` 契约）**：
  - 核对并补全 `window.__game.capture()`（返回原始 RGBA 供 `shotdiff`）、`window.__game.view()`（支持检查固定机位）、`window.__game.stats()`（补充 `jsMs`、可见怪物数、家具数）。
- **T0.3（建设 `tools/checks/` 全套门禁脚本与 `baseline.json`）**：
  - `tools/checks/smoke-check.mjs`：零 `pageerror`/零 `console.error`/零 `404`、标题→开局→模拟→暂停→重开状态机闭环。
  - `tools/checks/layout-check.mjs`：覆盖 `1280×720`、`1920×1080`、`844×390`（手机横屏）、`390×844`（手机竖屏），校验 44px 触控底线、零 `position: sticky`、零元素出安全区、零按钮被遮挡、零文字重叠。
  - `tools/checks/layer-check.mjs`：验证暂停/制作/日志/设置弹层的 4 种退出方式（按钮/遮罩/`Esc`/`history.back`）且不误触开局。
  - `tools/checks/palette-check.mjs`：自动截取白天林地、黄昏、黑夜林地、黑夜庇护所 4 个标准机位，断言 `L / p95 / dark / colorful / greenDom` 全部落在 `DESIGN_INVARIANTS.md` 区间内（M0 阶段先建立基线报告，M1 完成后开启硬拦截）。
  - `tools/checks/perf-check.mjs`：屏蔽绘制下跑 1200 帧（含 CDP `2x` CPU 降速），校验 p50/p95 与超帧数。
- **M0 验收标准**：`npm run lint` + `sim-check` + `smoke-check` + `layout-check` + `layer-check` + `perf-check` 全绿；浏览器零 404、零外链请求。

### Phase M1：主美视觉升维与“视野锥恐怖”重塑（Art & Lighting Overhaul）
> 目标：把画面质感从“绿草地 2D 原型”彻底拉升至对标参考视频的《阴暗森林》东欧腐朽油画风。
- **T1.1（程序化纹理、电影级树木与环境细节重构 `textures.ts` + `renderer.ts`）**：
  - 降低林地草地绿色饱和度，引入大片湿褐泥土、枯叶、灰绿苔藓斑块、浅黑积水洼与盘根错节的黑色枯枝根须（缠绕建筑墙角与树干周围）；
  - 重绘建筑墙体截断面（厚重近纯黑边框 + 不规则木石破损感），柔化地板与屋顶的规整接缝，加入旧油渍、裂木板与尘埃感；
  - **电影级树木升级**：重构树冠与树干烘焙（多层错落枝干与针叶/枯枝簇、强景深阴影叠层、爪状板根与青苔泥坑），实现顶视高度视差 + 分层相位错开的受风波浪摇曳 + 斑驳地面投影 + 受光边缘层次。
- **T1.2（“活的画面”动态动画：雨幕、水花与篝火 `engine.ts` + `renderer.ts` + `webglComposer.ts`）**：
  - **活的雨幕与水花**：升级双层景深雨丝 + 屋檐滴水飞溅 + 积水多圈涟漪扩散 + 雨点落地反弹微粒水花 + 积水洼地受光高光碎闪；
  - **活的篝火与余烬**：在庇护所壁炉/炭炉与猎人营地篝火实现多层跃动火舌、上升热烟、随风明灭飘散的余烬火星，以及带不规则柴火呼吸频闪的动态暖色点光。
- **T1.3（视野锥外记忆迷雾与隐匿敌人 `webglComposer.ts` + `renderer.ts` + `visibility.ts`）**：
  - 新增 `?v-palette` 与 `?v-vision` Variants（默认 `b`）；
  - WebGL2 合成器中，将视野锥外区域压暗并去饱和至冷灰暗影（保留微弱地形轮廓记忆）；
  - 门窗木板缝隙与破口在光源照射下投射**锐利条状光束**；
  - 强光源叠加克制的水平微眩光；
  - 敌人渲染层严格受视野锥/近身光圈/照明弹/闪电遮罩裁剪——**黑暗盲区中的怪物不可见**，仅暴露其制造的声波涟漪与门板受击木屑。
- **M1 验收标准**：`palette-check.mjs` 全部 4 场景指标达标；主美人工对比 `baseline_v0` 与新截图 + 参考帧 `ref_sheet_1..3.png` 确认过关；`?v-shader=a`（Canvas2D 回退）正常无报错。

### Phase M2：核心玩法深化——防线博弈、战斗手感与 30 秒开局钩子（Gameplay & Feel）
> 目标：让玩家“点开 30 秒就心跳加速，第一夜就手忙脚乱但有策略可赢”。
- **T2.1（可拖拽家具防线系统 `world.ts` + `engine.ts` + `renderer.ts`）**：
  - 在庇护所内放置 2–3 件可拖拽重型家具（旧沙发、橡木柜、工作桌），走近提示 `E 拖拽/松开`；
  - 拖拽时家具物理跟随并参与 `resolveWorldCollision()` 与怪物寻路阻挡；怪物攻击挡路家具时会将其撞退或损毁（发出沉闷撞击音效与木屑）。
- **T2.2（蓄力重击 + 闪避翻滚 + 战斗双尺手感 `engine.ts` + `renderer.ts`）**：
  - 鼠标左键支持短按快劈与长按蓄力（角色身上出现极克制的弧形蓄力微光，无廉价 UI 条），蓄力重击带强击退、`55ms` 顿帧与大片血迹贴花；
  - 新增 `Space` 闪避急退（带 0.18s 无敌帧、体力消耗与尘土轨迹），防止被怪物贴脸秒杀；
  - 调整夜袭 AI 节奏：怪物在进入攻击前先经历 `prowl_stalk`（门窗外短暂停顿窥伺、刮擦木板、发出低吼），给玩家预判与博弈窗口，杜绝“刚入夜瞬间暴毙”。
- **T2.3（30 秒开局钩子 & 3 夜「余烬逃生」完整闭环）**：
  - 第 1 天开局 8 秒内触发屋外轻度挠门声波事件 + 门外遇难者背包引导；
  - 在 3 处远方地标（坠毁货车、废弃锯木厂、枯林祭坛）各放置 1 个「信号中继零件」，拾取后带回庇护所发电机安装；
  - 集齐 3 件并在黑夜守住发电机直至破晓，弹出「破雾撤离」通关结算（含存活数据 +「继续无尽求生」/「重新开始」）。
- **M2 验收标准**：更新 `sim-check.ts` 覆盖家具拖拽碰撞、蓄力/闪避物理边界、零件收集与通关状态机；120s 自动试玩零卡死、零穿墙。

### Phase M3：物理驱动恐怖音效与心理压迫细节（Audio & Polish）
> 目标：戴上耳机就能仅凭声音分辨危机方向。
- **T3.1（立体声方位音频升级 `audio.ts`）**：
  - 为怪物脚步、刮擦门板、低吼、捕兽夹触发接入 `StereoPannerNode`，根据怪物相对玩家的 X/距离实时计算声像与低通衰减（隔墙时自动加重低通闷响）；
  - 新增家具拖拽木地板摩擦声、蓄力拉风声、闪避衣料摩擦声、以及发电机燃油低于 20% 时的间歇性熄火咳喘声；
  - 确保所有参数变化使用 `setTargetAtTime`，末端过软限幅器，切后台静音无爆音。
- **M3 验收标准**：无头音频状态机检查（解锁/静音/切后台/零异常）+ 人工试玩听感复核。

### Phase M4：全端 UI 克制打磨、移动端适配与终极发布验收（Release Gate）
> 目标：电脑键鼠与手机触控均可开箱即玩，全量门禁 100% 绿灯。
- **T4.1（极简 HUD 与触控体验补全 `App.tsx`）**：
  - 精简 HUD 信息密度，在左上角增加一行极克制的当前目标指引（如 `收集信号零件 0/3 · 探索林区地标`）；
  - 移动端触控新增「闪避」与「拖拽/交互」44px+ 按钮，确保双摇杆与操作热区零重叠。
- **T4.2（全量 Tier 1 + Tier 2 终验与文档封板）**：
  - 跑通所有自动化门禁，生成最终前后对比截图集（`docs/art/release_v1/` vs `baseline_v0/`）；
  - 更新 `DESIGN_INVARIANTS.md` 真实实测指标并输出最终交付报告。

## 四、子 Agent 开发纪律（发给 Gemini 4 Neon 的强制约束）

1. **每次只做一个独立任务包（如 T0.1–T0.3 或 T1.1）**，改完必须立刻运行对应的验证命令并汇报真实数据。
2. **禁止越权改标准**：子 Agent 不得修改 `DESIGN_INVARIANTS.md` 的红线数值或放宽 `tools/checks/baseline.json` 的阈值。
3. **禁止破坏单源真相**：不得在 `renderer.ts` 中写第二套碰撞/室内外判断，不得在已有 `expDecay` 上再叠平滑器。
4. **中文注释与代码整洁**：新增函数与核心逻辑使用清晰的简体中文注释，保持零 `tsc` 警告与报错。
